Ein kleines Update für das fertige Programm: Wer sein Passwort vergisst, kommt jetzt wieder hinein, und die Anleitung zum ersten Start stimmt für jedes System.

## Neu

- **Passwort vergessen?** Öffne im Ordner von Theta ein Terminal und gib `./theta reset-password deine@adresse.de` ein, unter Windows `theta.exe reset-password deine@adresse.de`. Theta zeigt ein neues Passwort an. Das geht auch, während Theta läuft.
- Auch `backup`, `restore` und `export` funktionieren jetzt direkt im Programm. `./theta hilfe` zeigt alle Befehle.
- Die `LIESMICH.txt` in jeder ZIP erklärt den Start für genau dieses System.

## Herunterladen und starten

| System | Datei |
|---|---|
| Windows | `theta-windows-x64.zip` |
| macOS mit Apple-Chip (M1 und neuer) | `theta-macos-arm64.zip` |
| Linux | `theta-linux-x64.zip` oder `theta-linux-arm64.zip` |

ZIP entpacken und `theta` mit einem Doppelklick starten, unter Linux im Terminal mit `./theta`. Der Browser öffnet sich mit der Einrichtung. Deine Daten liegen im Ordner `theta-daten` neben dem Programm. Wer von 0.1.0 kommt, legt das neue Programm einfach an die Stelle des alten und behält den Ordner `theta-daten`.

Das Programm ist noch nicht signiert. Auf dem Mac blockiert macOS deshalb den ersten Start: Öffne Systemeinstellungen → Datenschutz & Sicherheit und klicke bei „theta“ auf „Trotzdem öffnen“. Schneller geht es im Terminal mit `xattr -dr com.apple.quarantine` und dem Pfad zum entpackten Ordner. Unter Windows klickst du bei SmartScreen auf „Weitere Informationen“ und „Trotzdem ausführen“.

Auf einem Server mit Docker:

```sh
docker run -d -p 3000:3000 -v theta-daten:/data ghcr.io/hamido212/theta:0.1.1
```

Den Einrichtungs-Link zeigt `docker logs` an. Ein neues Passwort setzt `docker exec <Container> bun src/cli.ts reset-password deine@adresse.de`.
