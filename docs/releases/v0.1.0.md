Die erste Version von Theta: ein einfaches CMS für alle, die ihre Website selbst pflegen. Du klickst auf einen Text und schreibst, das Design bleibt stimmig, Besucher bekommen schnelles HTML ohne JavaScript, und die Website gehört dir.

## Herunterladen und starten

| System | Datei |
|---|---|
| Windows | `theta-windows-x64.zip` |
| macOS mit Apple-Chip (M1 und neuer) | `theta-macos-arm64.zip` |
| Linux | `theta-linux-x64.zip` oder `theta-linux-arm64.zip` |

ZIP entpacken und `theta` mit einem Doppelklick starten. Der Browser öffnet sich mit der Einrichtung, dort legst du dein Konto an. Deine Daten liegen im Ordner `theta-daten` neben dem Programm.

Das Programm ist noch nicht signiert. Auf dem Mac bestätigst du den ersten Start mit Rechtsklick auf `theta` und „Öffnen“. Unter Windows klickst du bei SmartScreen auf „Weitere Informationen“ und „Trotzdem ausführen“.

Auf einem Server mit Docker:

```sh
docker run -d -p 3000:3000 -v theta-daten:/data ghcr.io/hamido212/theta:0.1.0
```

Den Einrichtungs-Link zeigt `docker logs` an. Für den Betrieb im Internet gehört ein Proxy mit HTTPS davor.

## Was Theta kann

- **Direkt auf der Seite bearbeiten**, mit Vorlagen für ganze Seiten und einzelne Abschnitte, gemeinsamen Abschnitten für mehrere Seiten und Blöcken von Titelbild bis Karte.
- **Design, das nicht verrutscht:** fünf Vorlagen (Klar, Modern, Warm, Studio, Portfolio) mit Reglern für Farbe, Schrift, Abstände, Ecken und Hell/Dunkel. Fünf freie Schriften liefert die Website selbst aus.
- **Entwürfe, Verlauf und Papierkorb:** Änderungen gehen erst mit „Veröffentlichen“ online, frühere Fassungen lassen sich zurückholen.
- **Blog mit RSS**, Kontaktformular mit Postfach und auf Wunsch E-Mail, ohne Captcha und fremde Dienste.
- **Bilder ohne Vorarbeit:** automatisch verkleinert, ohne Aufnahmeort, mit Fokuspunkt. Videos und Karten laden erst nach einem Klick.
- **Gefunden werden:** Beschreibung, Vorschau für geteilte Links, Sitemap und Weiterleitungen, wenn sich eine Adresse ändert.
- **Die Website gehört dir:** Export als HTML für jeden Webhoster und eine Sicherung mit einem Klick, die du auf einem neuen Rechner gleich bei der Einrichtung einspielst.
- Öffentliche Seiten auf Deutsch oder Englisch.

## Noch nicht enthalten

Plugins, mehrsprachige Seiten und Rollen mit eingeschränkten Rechten fehlen noch. Für Macs mit Intel-Prozessor gibt es noch kein fertiges Programm.
